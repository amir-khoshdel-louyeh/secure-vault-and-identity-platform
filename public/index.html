Why Secure Vault?

Most apps encrypt only in transit. If the DB leaks, plaintext is exposed. This platform encrypts everything at rest and gives you full identity control.

🔐

AES-256-GCM Encryption

Every file and note is encrypted with random 12-byte IVs and 16-byte auth tags. Files stored as randomized .enc names; plaintext never persists on disk.

🛡️

Zero-Knowledge Mode

Optional client-side encryption via Web Crypto API (PBKDF2 100k + AES-GCM). The server stores only ciphertext — even the operator cannot read your notes.

📱

TOTP 2FA + Recovery

Two-step login (password → TOTP), QR provisioning for Google Authenticator / Authy, and bcrypt-hashed single-use recovery codes for device loss.

🔗

Secure Share Links

64-char hex tokens with expiry and usage limits. Revoke anytime in Managed Links. Shared notes render XSS-safe; ZK notes decrypt in the browser.

💻

Session & Trash Control

Database-backed sessions with IP / user-agent tracking and revocation. Soft-delete with 30-day Trash Bin — restore or delete forever.

📋

Defense-in-Depth

Multiple layers of protection keep your vault safe — from login to storage — so your private data stays private without getting in your way.
